# the azal — корпорация ИИ-агентов

Команда ИИ-агентов для управления контентом бренда мужской одежды **the azal**. Каждый агент — узкий специалист со своим промптом, правилами и форматом отчёта.

## Состав команды

| Агент | Файл | Задача | Статус |
|---|---|---|---|
| 🎬 Монтажёр (`editor`) | `.claude/agents/editor.md` | Видео из клипов, звук, текст, эффекты (FFmpeg) | ✅ готов |
| 💻 Разработчик (`developer`) | `.claude/agents/developer.md` | Сайт (HTML/CSS/JS), ссылки WhatsApp | ✅ готов |
| 🎨 Дизайнер (`designer`) | `.claude/agents/designer.md` | Обложки, промпты для Higgsfield (MCP), проверка визуала | ✅ готов |
| 📊 Таргетолог (`marketer`) | `.claude/agents/marketer.md` | Статистика (Windsor.ai), время постинга, хэштеги | ✅ готов |

## Структура проекта

```
the_azal_agency/
├── README.md
├── .claude/
│   └── agents/            ← описания агентов (YAML-шапка + системный промпт)
│       ├── editor.md
│       ├── developer.md
│       ├── designer.md
│       └── marketer.md
├── assets/                ← ваши исходники (агенты их НЕ меняют)
│   ├── clips/             ← видеоклипы
│   ├── audio/             ← музыка и звуки
│   └── fonts/             ← шрифты бренда
├── output/
│   ├── videos/            ← готовые ролики (Монтажёр)
│   ├── covers/            ← обложки (Дизайнер, создаётся при первой работе)
│   └── banners/           ← баннеры (Дизайнер)
├── site/                  ← код сайта (Разработчик)
└── reports/               ← отчёты (Таргетолог)
```

## Подготовка (один раз)

1. Установите [Claude Code](https://code.claude.com/docs) и войдите в аккаунт.
2. Для Монтажёра нужен **FFmpeg**: проверьте командой `ffmpeg -version`
   (macOS: `brew install ffmpeg`, Ubuntu: `sudo apt install ffmpeg`, Windows: `winget install ffmpeg`).
3. Положите материалы: клипы → `assets/clips/`, музыку → `assets/audio/`, шрифты → `assets/fonts/`, код сайта → `site/`.
4. **Важно:** запускайте Claude Code **из папки `the_azal_agency`** — только тогда он видит агентов из `.claude/agents/`:

   ```bash
   cd the_azal_agency
   claude
   ```

## Подключение внешних сервисов (MCP)

- **Higgsfield** (Дизайнер): подключите MCP-сервер Higgsfield в Claude Code (`/mcp`) и авторизуйтесь. Генерация тратит ваши кредиты — Дизайнер сначала проверяет баланс и просит согласие на дорогие серии.
- **Windsor.ai** (Таргетолог): подключите MCP-сервер Windsor.ai (`/mcp`) и в самом Windsor.ai добавьте аккаунты Instagram/TikTok/рекламы. Доступ у агента **только на чтение**: менять кампании и публиковать он не может.
- Проверить, что сервисы видны: введите `/mcp`.

## Как давать задачи агентам

Есть три способа.

### 1. Упомянуть агента по имени (самый простой)

Просто напишите в чате, кто должен выполнить задачу:

```
Используй агента editor: собери Reels из assets/clips/01.mp4, 02.mp4 и 03.mp4,
наложи assets/audio/night.mp3, в начале добавь текст "the azal" на 3 секунды.
Длина до 20 секунд.
```

```
Попроси developer проверить все ссылки WhatsApp на сайте и привести их к единому номеру 77011234567.
```

Claude сам запустит нужного агента в изолированном контексте и вернёт его отчёт.

### 2. Через команду `/agents`

Введите `/agents` — откроется список. Там можно посмотреть, отредактировать или создать агента, а также увидеть, какие инструменты ему доступны.

### 3. Автоматически

В описании каждого агента (`description`) указано, когда его стоит вызывать. Если вы пишете «смонтируй видео…» или «поправь кнопку WhatsApp на сайте» — Claude может выбрать подходящего агента сам.

## Примеры хороших задач

**Монтажёр**
- «Нарежь `assets/clips/lookbook.mp4` на 3 вертикальных ролика по 15 секунд для Reels».
- «Добавь плавные переходы между клипами и убери звук оригинала, оставь только музыку».
- «Сделай веб-версию ролика до 8 МБ для сайта».

**Разработчик**
- «Добавь кнопку "Заказать в WhatsApp" на каждую карточку товара, в сообщении — название товара».
- «Проверь сайт на телефоне (375px) и скажи, что "едет"».
- «Найди все неработающие ссылки WhatsApp и исправь».

**Дизайнер**
- «Сделай 2 варианта обложки 9:16 для ролика про чёрное пальто: сдержанно, серо-песочная палитра, место под заголовок сверху».
- «Проверь эту картинку на соответствие стилю бренда и найди артефакты».

**Таргетолог**
- «Посмотри Instagram за последние 60 дней: когда лучше постить Reels и какие форматы заходят?».
- «Предложи набор хэштегов для ролика про осеннюю коллекцию».
- «Как идёт реклама в Meta за последние 30 дней? Что отключить, что усилить?».

**Хорошая формулировка задачи** = *что сделать* + *из каких файлов* + *какой результат нужен* (формат, длина, где сохранить). Чем конкретнее, тем меньше уточняющих вопросов.

## Как работает отчётность

Каждый агент заканчивает работу структурированным отчётом на русском:

- ✅ **Готово** / ⚠️ **Частично** / ❌ **Не получилось** — статус в первой строке;
- какие файлы созданы или изменены и где они лежат;
- как проверен результат;
- замечания и допущения;
- рекомендуемый следующий шаг (например, «передать Дизайнеру»).

Если агенту нужно ваше решение, он предложит 2–3 варианта с рекомендацией.

## Типовой рабочий процесс (конвейер)

```
Монтажёр  →  Дизайнер  →  Таргетолог  →  (вы публикуете)
 ролик       обложка      время и хэштеги

Дизайнер  →  Разработчик
 баннер       обновление сайта
```

Агенты **не вызывают друг друга сами** — результат передаёте вы (или просите Claude: «возьми готовый ролик из `output/videos/` и отдай дизайнеру»). Так вы всегда контролируете процесс.

## Меры безопасности

- Исходники в `assets/` агенты **не изменяют и не удаляют**.
- Агенты **ничего не публикуют** в соцсети и **не деплоят** сайт — финальное решение всегда за вами.
- Перед необратимыми действиями Claude Code запрашивает подтверждение.
- Не кладите пароли и API-ключи в файлы проекта.

## Как изменить агента

Откройте нужный файл в `.claude/agents/`. Он состоит из двух частей:

```markdown
---
name: editor                 ← имя для вызова
description: ...             ← когда использовать (по нему Claude выбирает агента)
tools: Read, Write, Bash     ← какие инструменты разрешены
model: sonnet                ← модель (sonnet / opus / haiku)
---
Системный промпт: как думает, правила, формат отчёта…
```

Правьте промпт обычным текстом — изменения подхватятся при следующем запуске сессии (или через `/agents`).
